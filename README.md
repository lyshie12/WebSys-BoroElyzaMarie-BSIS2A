## 📌 Project Description

Elyza Digital Lab is my consolidated Web Systems and Technologies laboratory portfolio containing my work from Week 1 to Week 7.

The project demonstrates my learning and development in HTML, semantic web structure, CSS, JavaScript, Bootstrap, APIs, browser storage, Express.js, and MongoDB.

Each weekly laboratory was organized into its own folder and personalized with a consistent visual identity.

## 📚 Weekly Laboratory Summary

### Week 1 — HTML Fundamentals

Created a basic HTML webpage demonstrating fundamental HTML structure, headings, paragraphs, and page content.

**Folder:** `Week1_HTMLFundamentals`

### Week 2 — Semantic Multimedia

Created a semantic HTML webpage using sections and multimedia elements such as images and video.

**Folder:** `Week2_SemanticMultimedia`

### Week 3 — CSS Basics

Applied CSS styling, layout, colors, typography, forms, and responsive design to create a more organized and visually appealing webpage.

**Folder:** `Week3_CSSBasics`

### Week 4 — JavaScript Basics & DOM

Implemented JavaScript functionality and DOM manipulation, including dynamic content, theme switching, and interactive to-do features.

**Folder:** `Week4_JavaScriptBasicsDOM`

### Week 5 — JavaScript & Bootstrap

Used Bootstrap components and JavaScript to create a responsive and structured webpage with navigation, carousel, services, and multimedia content.

**Folder:** `Week5_JSBootstrap`

### Week 6 — API, Client & Storage

Worked with API-based features, JavaScript, browser local storage, user preferences, weather information, and GitHub API integration.

**Folder:** `Week6_APIClientStorage`

### Week 7 — Mini Full-Stack Starter

Created a mini full-stack web application using HTML, Bootstrap, JavaScript, Express.js, and MongoDB.

The application supports adding, displaying, and deleting users while storing data in MongoDB.

**Folder:** `Week7_MiniFullStackStarter`
