## Weekly Summary

### Week 1 - HTML Fundamentals
Created a basic HTML webpage demonstrating fundamental HTML structure, headings, paragraphs, and page content. The webpage was also personalized with the Elyza Digital Lab branding and styling.

### Week 2 - Semantic & Multimedia
Created a semantic HTML webpage using structured sections and multimedia elements such as images and video. The page was enhanced with consistent branding, typography, colors, and responsive styling.

### Week 3 - CSS Basics
Applied CSS concepts including colors, typography, spacing, borders, layout, forms, hover effects, and responsive design. The webpage was personalized to match the overall Elyza Digital Lab visual theme.

### Week 4 - JavaScript Basics and DOM Manipulation
Implemented JavaScript and DOM manipulation to create interactive features such as dynamic content, theme switching, a to-do list, keyboard interaction, and a contact form with modal feedback.

### Week 5 - Javascript Functions and Bootstrap
Used Bootstrap components and JavaScript to create a responsive webpage with navigation, carousel, multimedia content, services, and other interactive interface elements. The page was customized with the Elyza Digital Lab branding.

### Week 6 - API & Client Storage
Implemented JavaScript-based API integration and client-side storage features. The laboratory includes examples involving GitHub API, weather API, local storage, and user preferences.

### Week 7 - MiniFullStackStarter
Developed a mini full-stack web application using HTML, CSS, Bootstrap, JavaScript, Express.js, Node.js, MongoDB, and Mongoose.

The system includes a user management feature that allows users to be added, displayed, and deleted. Data is stored in MongoDB and can persist even after refreshing the webpage.
